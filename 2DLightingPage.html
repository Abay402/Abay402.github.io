2D Lighting System

Made in GameMaker, 2024

Summary:

A 2D Lighting System that can be utilized to light any room.

Roles:

Developer / Desginer

Videos

Main Video

Goals

The goal for this system was to utilize shaders to make vibrant and cool looking lighting without sacrificing performance.

Approach

To achieve this goal I made sure to have a lighting manager to controls all of the lights and shaders instead of having every individual light control that as it would be costly to have hundreds of lights accessing the graphics api at once.

Challenges

•

Configuring normal maps to work with this system

•

Displaying shadows

Results

•

Hundreds of lights can be placed with any color and any amount of strength and will light up the room and characters without costing performance.

•

The direction and angle of the light can also be modified to allow for specific lighting.

Features Implemented

Lighting System👁

This system uses multiple shaders to create the lighting effect in the project. There's a lighting controller object that controls the lighting for every light in the project. There can be about 500+ lights in the level before the FPS drops below 60. The size, strength, color, and direction of the light can also be easily changed per light.
