Baby Zombie Factory

Made in Unreal Engine 5, using Blueprints, 2023

Summary:

A 3D Shopkeeping game

Roles:

Gameplay Lead / Developer / Desginer

Goals

This was a full class project at College and the main goal for this project was working in a large team. The team was split into 3, Gameplay, Sound, and Level/UI Design. My goal was to demonstrate my ability to listen to the project and team leads and execute my tasks accordingly.

Approach

To achieve this goal I made sure to communicate with my team lead as much as possible and work together with other Gameplay Programmers to design and create the core game loop.

Challenges

•

Gameplay Team Lead was not as committed to the project as the rest of us and so I had to take over for him

•

Gameplay Team Lead as well as other Gameplay Programmers stopped working on the project with 2 weeks left as our professor was giving us leniency due to school scheduling issues.

Results

•

Took over as Gameplay Lead to ensure a complete gameplay loop as prior the loop was unfinished and buggy.

•

Designed and developed the core systems of the game such as the Incubator, Combination Machine, and Customer AI

•

Added smaller unplanned features like a trash bin to throw away unwanted parts and a visual feature that showed the finished zombie appearing on the counter before being sold to the customer.

Features Implemented

Customer AI 👁

I succesfully created a queue system where a customer would spawn in and check if any counter was available and would then move to it if there was. If not then they would wait in line until there was one available.

The customer when arriving to a counter would then give an order of zombie parts that they wanted. A timer would then start and if the player did not get an item to the customer in time then the customer would leave and score would be deducted.

Incubator

For the incubator we already had a rough UI system set up for it. I then improved the system by making it so that when the player picks a part in the UI, the machine goes into incubation mode and after a couple of seconds it spawns a zombie part that the player can pick up. I also fixed all bugs the incubator had with it's animations.

Combination Machine 👁

For the combination system, I made it so when the player activated it, it would take all of the player's zombie parts in their inventory and add it to the machine. Then the machine would activate and after a couple of seconds it would spawn a zombie with all of the parts that were added to it.

I wanted this system to be fun and unique instead of bland and boring so after discussing with the project leads we decided to change it so that the zombie limbs would be randomaly placed on each socket of the body. This allowed for some funny moments where the finished zombie body would have it's head where it's feet usually would be or have it's arm where it's head usually would be.
