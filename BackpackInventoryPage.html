Roles:

Goals

The goal for this system was to create a modular inventory system that would be similar to the systems in Resident Evil and Escape From Tarkov.

Approach

My approach for this system was to create a grid for the inventory so it would be easier to calculate inventory space and the amount of space an item takes up. I also decided to go further and add a backpack system on top of it where a backpack could be set to have different amount of storage.

Challenges

•

Translating UI items to real world objects

Results

•

Created a system very similar to Resident Evil where the player has to do inventory management to make items fit by rotating the items.

•

Communicated between UI and 3D by utilizing ScriptableObjects

Features Implemented

Inventory System 👁

To make the system dynamic and flexible, it utilizes scriptable objects where an item can be defined very easily. Also the size and the amount of grids of the backpack can also be changed dynamically. When adding an item to backpacks inventory it will first check if the player even has a backpack and if so then it'll check if the backpack has space. To do this the backpack has inventory grids where the system can easily check if there is available space or not based on if an item is already occupying that space. Also it checks if the item can fit in the inventory based on it size, if not then it'll try adding the item to another grid if there is one available, otherwise it won't add the item to the inventory.
