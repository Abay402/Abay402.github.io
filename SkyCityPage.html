Sky City Fugitive

Made in Unreal Engine 5, using C++ and Blueprints, 2024

Summary:

A 2d Platformer Soulslike Demo that takes place in a futuristic Cyberpunk-esque world

Roles:

Project Lead / Developer / Desginer / Artist

Goals

This was my Capstone Project at College and so I really wanted to create robust and dynamic systems. The systems being a persistent respawning system, a dialogue system and an event system

Approach

My approach for this project was to create these systems by communicating C++ logic with the Blueprints interface. I also wanted the dialogue system to be easy to edit and design so I opted for an XML structure to design the dialogue. I also wanted to make the event system work in hand with the other systems in the project.

Results

•

•

Created an event system that can modify gameplay behaviours, set off sequences, and combine with the dialogue system to allow dialogue to trigger events.

•

Made a persistent respawning system that is very similar to respawning systems you would find in other soulslikes.

Features Implemented

Event System 👁

The event system I created allows for any actor to subscribe to events that are triggered. For this demo some events that are triggered are; at the end of the opening dialogue an event is triggered that kills the guard and starts the game. Another event is towards the demo when the player activates a switch to turn off the prison alarm.

Dialogue System 👁

The dialogue system uses an XML to design the dialogue for the specific NPC including player responses. The XML file is parsed by a dialogue component that a speakable NPC has attached to them. This allows for unique dialogue or generic dialogue for NPCs on per basis.

Respawn System

The respawn system uses these "Recharge Stations" as beacons or checkpoints where when the player uses them, it becomes their new spawnpoint. Like any other soulslike, on death the enemies in the level are respawned as well as the player.
