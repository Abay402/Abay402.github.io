Summary:

A 2D Top-Down horde killing game

Roles:

Project Lead / Developer / Desginer

Goals

This was my Midstone Project at College and so I really wanted to showcase the skills I had learnt up to that point. This was also my first time leading other people on a project as I was the co-lead on the team.

Approach

For this project I emphasized communication amongst the team. Setting up weekly meetings and progress check as well as designing most of the systems. With the limitation of using a SDL Framework for the project, I really wanted to demonstrate my understanding of the library.

Challenges

•

Gun rotating towards the mouse location was a challenge in the framework

•

Limited with the amount of objects that could exist in one scene due to inexperience with the framework

Results

•

Created a workaround for enemy spawning and projectile spawning by reusing enemy and projectile objects instead of deleting them and creating new ones.

•

Improved knowledge of SDL and C++ allowed for dynamic gun rotations

•

Created a custom Item Drops system at the tail end of the project to make for better and unique gameplay experiences

Features Implemented

Item Drops 👁

The inspiration I had for this system was the drops system from Call Of Duty Zombies. I designed this system to have a random chance of dropping an item any time an enemy is killed. Then if an item is dropped it randomly selects from the list of items that are in the game.

Enemy Spawning

I set up over a dozen spawn locations that the enemy could spawn in and I put those locations into an array. Every time an enemy spawned after a set amount of time, the spawner class would randomly choose a location from this array and spawn that enemy at that location.
